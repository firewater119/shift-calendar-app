# 교대달력

소방공무원 교대근무를 확인하고 관리하는 Android 앱입니다.

## 다운로드

- [최신 APK Release](https://github.com/firewater119/shift-calendar-app/releases/latest)
- [한국어 사용자 설명서](USER_MANUAL.md)

## ⚠️ 안내 사항 및 저작권 표기

- **비공식 앱 안내:** 교대달력은 소방청 또는 특정 소방서의 공식 앱이 아니며, 개인 개발자가 비상업 목적으로 제작한 교대근무 달력 앱입니다.
- **공공저작물 출처 표기:** 앱 아이콘과 일부 이미지에는 소방청 및 지자체 소방본부의 공공저작물인 소방 캐릭터 **일구**가 포함되어 있습니다.
- **저작권 구분:** 교대달력의 소스 코드와 앱 기능의 저작권은 개발자에게 있으며, **일구 캐릭터와 관련 이미지 자산의 저작권은 소방청에 있습니다.** 해당 이미지는 소방청의 공공누리 이용 조건에 따라 사용되었습니다.
- 앱의 배포는 소방청의 승인 또는 공식 제휴를 의미하지 않습니다.
